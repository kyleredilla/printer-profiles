# 0.25mm Dart Box PLA test (process)

- **Parent:** copy of Dart box PETG
- **Status:** testing (fit tests)
- **Origin:** [Printing with PLA advice](https://claude.ai/chat/55c2e0c1-71c2-41d6-a611-69e7294c37bd)

## Purpose
Faster PLA version of the dart box preset for fit-checking the drawer, lid and base mount.

## Settings changed (vs. parent)

| Setting | Parent / before | Value | Why |
|---|---|---|---|
| Walls outer / inner | 80 / 120 | 120 / 180 | PLA bridges and cools more easily. |
| Infill / solid / top / gap | 150 / 120 / 80 / — | 200 / 180 / 120 / 120 |  |
| Bridges | 25 | 35 mm/s | PLA bridges well at this speed with full fan. |
| Accel default / outer / inner / travel | 3000 / 2000 / — / — | 4000 / 2500 / 4000 / 4000 |  |
| Travel | 300 | 400 |  |

## Unchanged from PETG
- 0.25 mm layers, 5 walls, supports off + don't support bridges, thick bridges, back seam, 5 mm brim, EF comp 0.15.

## Lessons from the PLA test prints
- Box corners lifted with no glue: clean the PEI, bed 60–65 °C, 8 mm brim, fan off early layers, block drafts.
- The lid lifted in the middle where a spiral of glue left bare stripes: coat the whole footprint evenly and mesh the bed hot.
- The drawer-opening bridge sagged badly, which is what led to the Rev B header support.

## Caution
- Don't run the heater long in a PLA box: the heater film can reach the 73 °C fuse limit under the false floor, and PLA softens at ~55–60 °C.
