# 0.24mm Tall Part - Adapter RevB (process)

- **Parent:** `0.24mm Draft @Elegoo N4Plus 0.4 nozzle`
- **Status:** active
- **Used by:** tall PETG adapter Rev B; any tall, narrow part
- **Origin:** [Printing with PLA advice](https://claude.ai/chat/55c2e0c1-71c2-41d6-a611-69e7294c37bd)

## Purpose
Tall-part version of Draft: slower and gentler so a tall part on a moving bed doesn't wobble or detach, with supports allowed to start on the part.
